# Smart Study Planner

## Project Description

Smart Study Planner is a simple Python-based application that helps students organize their study time and track their learning progress.

The program takes subject details such as number of topics, difficulty level, available study hours, and completed topics. It then calculates study priority, hours per topic, progress percentage, and gives a study recommendation.

## Features

- Add multiple subjects
- Set subject difficulty
- Calculate study priority
- Calculate hours per topic
- Track completed topics
- Calculate progress percentage
- Provide study recommendations

## Technologies Used

- Python

## How It Works

The user enters the following information:

Subject Name, Number of Topics, Difficulty, Available Hours, Completed Topics

Example:

Python 8 medium 6 6

The program then calculates the study plan and displays the progress and recommendation.
